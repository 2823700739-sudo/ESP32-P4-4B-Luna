# 用手机设置 Luna

**2026.11.27 定版**已包含本页手机设置流程。没有热点网页的旧固件先按[部署教程](DEPLOYMENT.md)升级；时钟、天气和专注无需 Windows Agent。

## 时钟与天气：不需要电脑脚本

1. **给 Luna 供电。** 首次没有 Wi-Fi 设置时自动开启热点；已有设置时，切到天气卡，点击右下方 **Wi-Fi**。
2. **手机连接设备热点。** 屏幕弹窗显示 `Luna-Setup-…`，**无需密码，直接连接**。手机提示“无互联网”时选择保持连接。
3. **浏览器打开 `http://192.168.4.1`。** 不保证系统自动弹页；使用 HTTP，不是 HTTPS。
4. **点击“扫描 Wi-Fi”，选择家中 2.4 GHz 网络。** 输入该网络密码，再点“连接并继续”；选中网络不会自动连接，切换选择会清空旧密码。也可手动填写名称（区分大小写）。此步只在内存中试连，不改原有已保存设置。
5. **选城市，再保存。** 等 Luna 联网校时后搜索，核对省份/国家；找不到时可手填地点名与明确经纬度。城市由 Luna 查询，手机不必能上网。点击“保存到 Luna”。

Wi-Fi 扫描结果以逐行列表显示名称、信号与是否需要密码，点选后高亮。连接与保存按钮下方分别显示进行中、成功或失败，结果变化时自动滚动到提示；请求中断则先查询状态，显示“正在确认”，不要重复提交。

设备配置弹窗显示期间，屏幕其他区域的点击、滑动及待机入口均被屏蔽；点击“暂时隐藏”可恢复卡片操作，热点继续开放。点击“关闭热点”才结束配置。

网页分别显示**已保存、Wi-Fi 在线、最新天气就绪**。密码错误可重新试连，不能把保存当联网。保存且联网后约 20 秒关闭热点；否则最多开放 10 分钟。屏幕 **暂时隐藏** 只隐藏弹窗，**关闭热点** 结束配置。未保存试连在关闭/超时后恢复上次提交网络；首次没有旧网络则停止试连。重新进入时以屏幕显示的热点名称为准。

设置保存在设备 NVS，重启无需重配。天气与 NTP 时钟由 Luna 独立联网，时区仍为北京时间。完成后手机可接回日常 Wi-Fi。

## 电脑相关功能：再运行 Windows 脚本

音乐/音量、CPU/GPU/内存、VS Code 工程和 Codex 额度需要电脑来源。按部署教程在 Windows 手动配对 Luna，安装 Python 3.11 x64 后运行 **Start-Luna.cmd**，它会建立当前用户登录常驻。正常启动不再询问天气；只用时钟/天气无需运行。

`Configure-Weather.cmd` 保留为可选的已认证 BLE 兼容入口，见 [BLE 配置说明](WEATHER-SETUP.md)，手机设置无需运行。

## 更新与排障

- 已有 Luna 且分区相同：新 app 写 **0x20000**，保留配对/NVS；只有允许清数据首装才用合并 bin 写 **0x0**，会清配对、网络、地点/缓存。不刷 C6。
- 找不到热点：保持 DC 供电，点天气卡 Wi-Fi，观察屏幕。“Wi-Fi 初始化失败，错误码 …” 表示初始化失败，报告错误码给维护者；现有 C6 可能缺少兼容 Hosted Wi-Fi RPC，不自动擦除/刷 C6。
- 手机切走热点：选择“保持连接/仍然使用此网络”，必要时暂时关闭手机自动切网。没有 NAT/互联网共享，“无互联网”不表示网页失败。
- 扫描为空/失败：确认是 2.4 GHz 网络，稍等几秒重新扫描，或手动输入名称；隐藏网络需手填。正在连接网络时可能暂不能扫描，不会为了扫描清空旧设置。
- 搜索失败：检查 Wi-Fi/校时状态，等待 NTP，试拼音，或手填坐标。设备网络需能访问 DNS、NTP 和 Open-Meteo HTTPS。
- 保存后断线：先观察设备；重进热点后读状态，不重复发送。成功关闭热点是预期行为。
- 普通联网故障不会偷偷重开热点；从屏幕重新进入，勿为排查先清 NVS/配对。

## 隐私与技术

按用户选择，配置热点**不设密码**，最多一台手机、最多 10 分钟。HTTP 只接受 AP 目的地址，并校验 Host/Origin/会话 token，不向家庭局域网开放页面。无 CORS、DNS 劫持、NAT、CDN、localStorage、账号或额外云服务。

Wi-Fi 扫描由设备本地执行，列表最多 16 项，同名同加密类型去重，仅返回名称/信号强度/是否需密码，不返回 BSSID/MAC，也不写入电脑或城市服务。列表中的开放网络不代表已验证可信。

密码只用于手机到设备的本地配置，不发送给城市服务、不在状态接口回显、不写电脑文件/日志。开放热点和本地 HTTP **不提供无线传输加密**，配置时附近设备可能接入或监听；请只在需要配置时开启。Host/Origin/token 用于防跨页面误提交，不能替代无线加密。当前未提供 Flash/NVS 静态加密，勿分享设备 Flash 镜像。

城市查询由设备 HTTPS 访问 [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api)，数据来自 [GeoNames](https://www.geonames.org/)。底层使用现有 [ESP-Hosted AP+STA](https://github.com/espressif/esp-hosted-mcu/tree/main/examples/wifi/apsta) 与 ESP-IDF 本地 HTTP Server；具体 C6 组合仍需实机验证。

# 连接状态与恢复

本页对应 **2026.11.28 定版**，内置应用 **2026.11.28-computer**。蓝牙与 Wi-Fi 改进随本版源码、固件和 Windows 使用包一起提供。

当前应用已仅更新 app 并通过写后哈希，90 秒启动观察确认既有 Wi-Fi、HTTPS 天气和 NTP。已有绑定的认证加密 BLE 重连及 CPU 发送/设备应答一致通过；用户确认显示和触摸顺畅，随后确认 CPU 大致一致、B 版显示正常。此前连接候选三次会话共 53 次心跳通过；另有一次强制 20 字节小分包会话超时，原因未定位，随后小分包及常规会话通过，仍保留待观察。

上述结果不覆盖全新数字配对、移除旧绑定、重新配置家庭网络、断电或 Windows 休眠恢复及长时稳定性。中文配对弹窗已在真实 LVGL 原生模拟验证；保留旧绑定，未通过删绑定强制测试实物弹窗。详见[发布清单](../firmware/releases/2026.11.28/manifest.json)。

## 蓝牙

界面区分“准备中 → 等待连接 → 连接中 → 已配对 → 已连接”；异常时显示中文提示。只有本次会话通过安全校验和握手才显示已连接。音乐快照过期只影响对应控件，不把已连接会话误报为未连接。

产品配对界面改为月夜配色的中文圆角弹窗，显示六位核对数字、双端人工确认说明、“不一致”和“数字一致”。配对优先于其他弹窗，显示时唤醒、关闭时长编辑和音量浮层，阻止底层点击、滑动、导航及待机；原专注计时继续运行。关闭后重新计算普通待机时间。

按下与松手必须属于同一配对挑战；新数字到来时丢弃旧按压。每次数字核对有独立标识，跨任务读取使用一致快照，旧界面不能确认新挑战。保留认证、加密、绑定、16 字节密钥以及双端人工核对，不自动配对或放宽安全门槛。

旧配对恢复提供“暂不处理”，仅关闭此次提示；用户明确选择移除时只处理发起请求的电脑。失败显示中文结果并可重试，成功提示在 Windows 重新添加 Luna，不清空所有绑定或设备配置。

Windows Agent 的通知订阅最多等待 10 秒；停止通知清理最多等待 3 秒，并保留原始错误或取消结果，然后交由 Bleak 断开。重新连接仍建立新会话，不重放结果未知的音乐动作。

## Wi-Fi

无线事件和恢复定时器只向后台任务提交请求，所有同步连接操作由该任务执行。即时 RPC 失败和未获得 IP 都保留 30 秒恢复检查；丢失 IP 立即撤销在线状态，对仍关联但没有 IP 的状态执行受控断开后重连。扫描期间暂缓连接，结束后继续恢复。

新试连清除前一网络的重试计数和定时器。取消未保存的网络后，迟到 IP 事件不能重新标记在线。手机扫描列表、连接和保存各自的反馈及原配置恢复规则保持。

## 界面参考与代码整理

布局参考 [LVGL 9.3 Widgets 示例](https://github.com/lvgl/lvgl/blob/v9.3.0/demos/widgets/lv_demo_widgets.c)及 [Material Web Dialog](https://github.com/material-components/material-web/blob/main/docs/components/dialog.md)的模态与操作层次。Luna 继续用现有 LVGL、字体、星空与像素猫素材自行实现，没有复制第三方代码或引入新 UI 依赖。

断开与主机复位共用会话清理入口。产品不再创建英文诊断页面，独立 B0 诊断构建保留，避免将有配置条件的兼容路径误当死代码。全仓引用审查未找到可直接大段删除的业务函数，生成图标与第三方资源按原来源维护。

网页预览增加“蓝牙界面演示”，可查看中文配对、旧配对恢复、等待与异常状态；全部是示例，没有真实无线或媒体动作。真实 LVGL 原生渲染与受控故障测试可验证逻辑和布局，不能代替设备上的 Windows 断电重连、睡眠恢复与长时运行验收。

# Luna 无线首版：UI 开源参考与设计基线

研究日期：2026-10-02。范围为五卡与圆盘待机时钟，未下载或导入第三方图片、字体与主题。
用户已确认本页范围与交互方向；[U0 五卡/宠物/待机交互预览](u0-ui-preview.md)第一版已完成，
用户已确认本版完整视觉效果，现进入 B0；不代表固件已实现。
产品范围见 [v2.1 立项](../ideas/luna-desktop-companion.md)。电脑卡比较预览已选“双圆环＋内存条”，
预览中的百分比/温度是示例数据，不能视为电脑传感器验收。

## 1. GitHub 项目筛选

| 项目 | 值得参考的部分 | 与 Luna 的关系和限制 | 采用决定 |
| --- | --- | --- | --- |

| [LVGL Extended Demos / Smartwatch](https://github.com/lvgl/lv_demos/tree/master/src/smartwatch) | 彩色圆弧、紧凑天气、滑动与日期布局 | 主界面是数字时钟；代码推荐 384×384，不是现成三针表盘；独立仓库授权和 9.3 兼容未确认 | 第二优先：仅借鉴圆形构图与天气层次，不整包移植 |

| [Infineon LVGL Smartwatch](https://github.com/Infineon/mtb-example-psoc-edge-gfx-lvgl-smartwatch) | 智能手表布局、闲置切换、触摸唤醒 | 面向 PSOC Edge / SquareLine；主许可是 Infineon EULA，不是通用 MIT 示例 | 只作为交互资料，不导入厂商代码和素材 |

推荐结论：用“LVGL 原生音乐控件 + 仪表盘的信息层级 + 智能手表的圆形布局”组成自己的
Luna 风格。不是选一个完整 Demo 来替换工程；目前 UI 的滑动、按钮反馈和局部创建机制值得保留。

LVGL 核心的 [v9.3.0 MIT 许可](https://github.com/lvgl/lvgl/blob/v9.3.0/LICENCE.txt) 需保留相应版权声明；
单独素材和其他仓库仍须逐项核实，不能因为使用 LVGL 就默认都可复用。
[Music README](https://github.com/lvgl/lvgl/blob/v9.3.0/demos/music/README.md) 说明它的频谱数据由音频预先生成，
不是 Windows 当前音乐的实时频谱；本项目不为装饰动效新增 PCM/音频流。
[Infineon LICENSE](https://github.com/Infineon/mtb-example-psoc-edge-gfx-lvgl-smartwatch/blob/master/LICENSE)
有特定硬件使用条款，因此本项目不将其厂商代码当成可直接移植的开源组件。

## 2. 一致的视觉语言

方向：月夜桌面伙伴。安静、柔和、有一点活泼，而不是电竞监控大屏。

- 屏幕 720×720；第一版沿用 590×450 卡体，周围留轮播空间；新增内容须先验证中文字体与边界。
- 深蓝灰底 `#101827`，卡底 `#1C293C`，主文字 `#F1F5FB`，次文字 `#A9B7CC`。
- 音乐用暖橙 `#FFBC82`，天气用天蓝 `#86CCFA`，额度用淡紫 `#B8A2FF`，电脑用薄荷 `#81DEBB`。
- 卡片圆角 28–32 px、边距 24–28 px；只用少量阴影/细描边，不堆透明大图层。
- 标题 24–28 px，主要数字 42–64 px，正文 18–22 px。现有中文字库不足时先补字体资源预算，不能假设大号中文已可用。
- 播放/暂停为最大按钮，其余触控目标建议至少 48×48 px；滑块与整卡滑动必须分离事件。
- 连接状态用文字加图标，而非仅颜色。旧数据有“上次更新”标记，未知值不画满条或空条来冒充真值。
- 触摸小幅缩放/回弹约 120–220 ms；离屏动画停掉。不为“生动”增加无依据的实时频谱或大 Lottie 资源。

以上尺寸和颜色是初始设计建议，待屏幕预览及实机触摸后调整，不是新增硬性承诺。
开机固定显示数字时钟卡；每次只突出一张大卡，左右滑动切换，不改成多功能挤在一屏的仪表盘。

## 3. 五张卡的具体设计

| 卡片 | 视觉与布局 | 必须保留的语义 |
| --- | --- | --- |
| 音乐 | 左侧固定唱片/圆形 Luna 标识，右侧歌名歌手；下方三键，最底部系统音量与静音 | 所有歌曲同一图形；可播放时才启用控制；暂停停转，无媒体显示“等待音乐” |
| 天气 | 大天气图标搭配主温度，地点与日期在顶栏；体感/湿度等做成小胶囊 | 晴/雨/夜间按真实天气字段选择本地图形；更新时间、缓存和 Wi-Fi 错误可辨 |
| 时钟 | 默认开机卡；大数字时间、日期星期、宠物，月夜装饰和简洁同步提示 | BLE 优先校时、Wi-Fi NTP 备用；无有效时间不显示假时间 |
| Codex | 两条独立圆角剩余额度条，下方仅一个“当前 VS Code 项目”及更新时间 | 额度与工程分别来自 Codex/VS Code；未知用灰色轨道加“--”，不当作零 |
| 电脑 | CPU/GPU 双圆环，中间大百分比、环下温度；下方内存/显存两条横条与已用/总量 | 已选布局；明确机器/GPU，同口径采样，不支持的指标显示不可用 |

额度卡最小布局：

```text
CODEX                         蓝牙已连接

5 小时剩余                         72%
[======================----------]

周额度剩余                         41%
[=============-------------------]

当前 VS Code 项目   ESP32-P4-4B-Luna
上次更新  14:32
```

工作区过长只在受限区域截断/按需滚动，不展示完整敏感路径。项目必须来自 VS Code 桥接，
跟随最近操作窗口；切到浏览器保留，切到另一个工程更新。桥接断开标记上次信息，不用 Codex 线程推断顶替。
音乐不增加未经媒体接口支持的进度拖动。唱片播放时轻转、暂停停转；音量控制展开时点滑块区域外
立即收起，并执行所点的其他按钮动作，不要求再点一次。拖动滑块不能误触整卡滑动。

电脑卡先交付已选圆环/横条布局，趋势线暂不作为必需项，避免在 590×450 里塞满监控图表。
天气不用高分辨率照片，晴云雨雪图形可用原生绘制或授权明确的小图标。

## 4. 待机圆盘时钟

- 全屏表盘直径初始建议约 520 px，中心接近 `(360, 330)`，下方留日期与同步提示空间。
- 60 个细刻度，12 个主刻度，四个主要数字；时针短而粗，分针长，秒针细且带点缀色。
- 时针包含分钟进度，分针包含秒进度；不能每小时/每分钟才跳一次。
- 先实现每秒更新，平滑秒针作为后续可选优化，不承诺 60 FPS。
- 由 LVGL 原生线条/刻度与本地时间驱动，不传输表盘帧，不依赖第三方厂商图片。
- 无触摸 180 秒（3 分钟）进入，第一次触摸只唤醒回之前的卡；后台播放/天气/BLE 不退出待机。
- 宠物在表盘外角落睡觉，有轻微呼吸动画；不能盖住刻度、日期或同步提示。
- 降低背光可作为可选设置；本轮不进入 P4 深睡眠，也不沿用其他芯片 Demo 的低功耗数字。

## 5. Luna 像素宠物

用户授权由本项目设计生成像素风角色；“月亮小猫”是初始创作方向，不是已经批准的最终形象。
应先给形象与动作预览，再选择最终素材。用户确认的是：自主活动、可点击互动、不与业务状态绑定。

- 平时在卡片外的屏幕四周活动：走动、停留、坐下、打盹；点击时短暂回应后继续自己的活动。
- 待机切为角落睡觉、轻微呼吸；首次点击仅唤醒，恢复原卡与宠物活动，不穿透功能按钮。
- 素材透明背景、统一像素密度，放大用最近邻；角色轮廓/颜色在各帧保持一致。
- 第一版优先少量可验证的走路、待机、回应、睡觉帧；不要求 ChatGPT Pets 的九状态/十六方向格式。
- 不遮挡文字、播放键或音量条；拖动卡片优先，宠物命中区域有界，不让透明图片矩形吞掉整片触摸。
- 动画和位置本地驱动，不经 BLE 发送；同时只存在一只，切卡不创建多个宠物实例。
- 以生动友好为目标，不制造弹窗、频繁提醒或把装饰动作伪装成业务进度。

## 6. 非 UI 的配套参考

[LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 是传感器采集候选，
不是漂亮主题来源。它提供多厂商硬件指标，但部分传感器需要管理员权限；主许可 MPL 2.0，
另有第三方条款。先用不提权的 CPU/RAM 和适配的 GPU 指标完成首版，再评估温度 helper，
不直接把它整个界面搬到 Luna，也不默认安装驱动或启动管理员服务。

## 7. UI 预览与落地检查

1. 固定实际要复用的版本与代码/素材许可，记录来源，不从 latest 分支整包复制。
2. 先提供五卡＋宠物＋待机的完整交互预览；720×720 与 590×450 卡体检查正常/空/过期/离线/长中文，标明示例数据，取得用户效果确认。
3. 再落地固件，真机验证字体、音量外点不吞按钮、五卡切换、宠物命中、3 分钟待机唤醒与动画资源释放。
4. 并测 BLE + Wi-Fi 天气、内部 RAM/PSRAM 和 8 小时运行后再决定动画强度。
5. UI 预览通过不等于蓝牙、Windows 媒体控制或硬件指标采集通过。

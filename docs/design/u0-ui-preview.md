# U0：月夜五卡与宠物交互预览

日期：2026-10-02。状态：用户已确认本版 UI，作为无线首版实施基线。
这是仓库中的设计原型，不是新版固件；没有烧录板卡、切换 Agent、占用串口或启用 BLE。
TF 实机检查属于[独立验证](../development/tf-readonly-validation.md)，不在本轮重复执行。

## 打开预览

在仓库根目录执行：

```powershell
.\scripts\preview-luna-ui.ps1
```

打开 [本机预览](http://127.0.0.1:8773/design/preview/)。服务器只绑定 loopback，
不暴露到局域网，按 Ctrl+C 结束；端口冲突可传 `-Port 8774`。
源码入口为 [preview/index.html](preview/index.html)，需通过本地服务器运行 ES modules，
不是双击 `file://` 打开。页面不调用 Agent，不连接蓝牙/串口，不读取真实电脑硬件或账号额度。
时钟使用浏览器本地时间；业务、位置与连接状态全部明确标为示例。

## 本轮交付

- 720×720 屏幕、590×450 卡体；柔和月夜色板，开机默认数字时钟。
- 整个屏幕共用繁星背景，星点不进入卡体内容；待机时保留表盘外的星空。
- 五卡横向滑动、箭头/底部导航及左右键切换；当前卡之外不保留业务卡 DOM 和动画。
- 固定唱片音乐控制，播放旋转、暂停停止；标题/歌手、三键、系统音量与静音都是本地模拟。
- 音量区域外按下立即收起，点击媒体键仍执行；滑块拖动不切卡，拖到屏幕外松开也能恢复待机。
- 独立 Wi-Fi 天气的视觉；蓝牙断线仍可显示天气，Wi-Fi 断线明确显示缓存。
- 两条独立剩余额度条和一条 VS Code 项目；未知窗口显示 `--`，不冒充额度为零。
- CPU/GPU 双圆环与温度、内存/显存横条；缺失数据明确为不可用，不伪造传感器值。
- 一只自主走动/停留的月亮小猫，点击有短暂回应；切卡不增殖，不随业务值改变动作。
- 180 秒无屏幕交互进入三针表盘，宠物在角落睡觉/呼吸；第一次触摸只唤醒回原卡。
- 待机不改变音乐状态、不停止后台服务语义，暂停隐藏卡片动画；无有效时间不显示假指针。

预览场景：正常、电脑/Wi-Fi 离线、无数据、过期、部分指标缺失、长中文、仅 BLE 断线、仅 Wi-Fi 断线。
场景切换是预览工具的“后台数据变化”，不唤醒待机、不重置设备交互倒计时。
“预览待机时钟”是快速查看效果的工具，不改变正式 180 秒阈值。

## 点击小猫无回应：内置浏览器复现与修复

用户反馈后，在用户当前 Codex 内置浏览器页面复现：小猫停在屏幕原点，
点击按钮未出现回应，倒计时停在 `181 秒`。该页控制台记录
`petPosition` / `animate` 的 `Cannot read properties of undefined (reading '0')`。
这是动画初始化时间边界没有防护，导致路径索引无效，首个动画回调抛错后未继续调度；
只检查 Chromium 正常帧时间和点击按钮的首版测试不足以覆盖该环境。

修复：动画与触摸统一使用 `performance.now()`，帧差限制为非负；
路径入口把负数/NaN/Infinity 防守为初始位置，倒计时不超过 180 秒。
启动先绘制宠物位置，点击时立即绘制回应，不依赖下一次动画帧；
按住期间冻结移动并捕获指针，松手/取消后释放，不会让它在按下和抬起间跑走。

修复后在用户实际内置浏览器刷新并验证：点击出现“喵～”，移动和时钟秒数/倒计时继续更新；
进入待机后点击睡觉小猫只唤醒、返回原时钟卡，没有穿透出回应；再点可正常互动。
本次新增两项状态边界回归，28 项状态测试通过；不涉及生图重做、固件、串口或 BLE。

## 停留后恢复走动的瞬移修复

停留期画面锁定位置，但原实现继续推进路径时间，恢复时跳过了约 3 秒的路程。
现将活动周期与实际走路时间分开：每周期走 13 秒、停 3 秒，
停留只推进周期而不推进路径；点击回应、按住、待机期间也不推进活动路径。
恢复时沿停下的位置继续，不添加过渡动画来遮掩错误坐标。

新增四项回归：3 秒停留坐标固定、恢复边界坐标相同、30 个周期的停留/恢复连续性，
以及 10 个周期逐 16 ms 检查位移不超过正常路径速度。全部 32 项状态测试通过。
当前内置浏览器连续采样：停留阶段坐标保持 `(660, 85)`，恢复后为 `(660, 85.718)`；
两次采样相隔 265 ms，位移约 0.718 px，没有再跳过停留期对应的路程。

## 整屏繁星背景调整

按用户要求，星空属于整个 720×720 屏幕的背景，不是五张卡片的内部装饰。
底层使用本地原生 SVG，240 个固定星点分为三档大小、颜色和亮度；
顶部品牌/连接文字和底部导航周围留白，少量亮星以 7 秒周期轻微明暗变化。
减少动态效果偏好下关闭闪烁。没有流星、背景平移或新增业务状态联动。

卡体继续使用原来的不透明底色，尺寸、内容和布局不变；待机层背景改为透明，
共用底层星空，而圆盘表面仍然不透明。背景层不接收指针事件，不遮挡小猫/控件。
预览服务器明确使用标准 `image/svg+xml` 类型，避免 Windows MIME 注册表返回
`image/svg` 导致浏览器不绘制星点；服务仍然只绑定 loopback、只提供 docs 目录。

本次 32 项状态测试通过，JS 语法与 diff 空白检查通过；在实际内置浏览器查看
时钟卡/音乐卡/待机效果，确认切卡、播放按钮、小猫回应及首触摸唤醒正常，
页面无 error/warn 日志。截图保存在忽略目录 `preview/review/starry-screen.jpg`
和 `starry-idle.jpg`。仅更新设计预览，未修改/烧录固件、未占用 COM27/COM28。

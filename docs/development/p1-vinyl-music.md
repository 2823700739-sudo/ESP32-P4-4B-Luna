# 黑胶音乐卡实机验证

本文记录上一版的三档音量按钮。当前版本请使用
[590×450 音乐控制卡实机验证](p1-music-controls-590x450.md)。

## 本轮效果

- 音乐卡中央改成黑胶唱片：深色盘面、同心纹路、圆形专辑封面及右上方唱臂。
- 底部保留上一首、播放／暂停、下一首，全部使用图标。播放键位于中间，图标跟随 Windows 返回的真实播放状态切换。
- 右下角音量图标展开三个图标按钮：上方加大音量、中间静音／取消静音、下方减小音量。它们控制 Windows 系统音量，因此作用于当前使用的电脑音箱；卡片不显示音量数值。
- 黑胶和唱臂由 LVGL 图形绘制，封面沿用原有 JPEG 数据。当前没有持续旋转动画，以免影响卡牌滑动和 Wi-Fi 稳定性。

## 烧录与准备

在项目根目录执行：

```powershell
.\scripts\build-firmware.ps1 -Action flash-full -Port COM27
```

本轮未改 Windows 助手代码；确认电脑上的助手正在运行、面板显示 PC 就绪。随后打开网易云音乐并播放一首带封面的歌曲。若 COM27 正被串口监视器占用，先用 `Ctrl+]` 退出监视器。

## 实机检查

1. 滑到音乐卡，确认黑胶位于卡片中央，专辑封面被裁成圆形，唱臂位于唱片右上方。歌名、歌手和底部按钮不能被遮挡。
2. 点击播放／暂停，确认网易云实际状态变化后，中心图标在播放与暂停之间切换；较快点击时也不能永久显示反状态。
3. 点击上一首、下一首，确认歌曲、封面及图标正常更新，不发生复位。
4. 点击右下角音量图标，确认弹出“加、静音、减”三个图标。分别点击，检查 Windows 音量和电脑音箱的实际变化；再次点击音量图标应收起弹层。
5. 暂停音乐后继续测试音量按钮；完全退出网易云后，音量按钮仍应能控制 Windows 系统音量。
6. 连续左右滑动 30 次，经过音乐卡和其他卡片；检查有无半屏黑块、明显掉帧、图层残留或复位。离开音乐卡再返回，封面与按钮应重新出现。

# 卡片滑动与果冻回弹实机验证

> 本页记录当时三张卡片的版本。当前新增了壁纸时钟卡，四卡轮播验证见
> [壁纸时钟卡实机验证](p1-clock-card.md)。

## 本轮改动

- 卡片容器固定在屏幕上，只移动当前卡和左右邻卡。这样下一张卡进入屏幕时，
  不会被已经移走的容器边界裁掉。
- 三张逻辑卡片各创建一次，切换时复用对象和已加载的音乐封面；滑动结束只重新
  排列位置，不重建整张卡片。
- 过渡时长为 340 毫秒，缓出后轻微越过目标位置并回弹。
- 相邻卡片保持正常亮度，减少透明混合带来的绘制负担。

当前总共只有 `CODEX`、`MUSIC`、`WEATHER` 三张卡，所以保留三张对象正好符合
“当前卡和左右邻卡”的内存范围。

## 烧录

在项目根目录运行：

```powershell
cd D:\Documents\ChatGPT\ESP32-P4-4B-Luna
.\scripts\build-firmware.ps1 -Action flash-full -Port COM27
.\scripts\build-firmware.ps1 -Action monitor -Port COM27
```

串口监视器使用 `Ctrl+]` 退出。本页记录的是当时的构建结果；当前固件已移除
语音模型，最新烧录与验证步骤见[无语音版本实机验证](no-voice-validation.md)。

## 实机检查

1. 从 `CODEX` 向左滑到 `MUSIC`，观察整个过渡过程；屏幕中间不应突然出现
   半屏黑色区域。两卡之间只会露出原有的窄背景间隙。
2. 继续向左滑到 `WEATHER`，再向左回到 `CODEX`，确认三张卡循环顺序正确。
3. 反方向重复一轮，检查卡片进入屏幕时是否有被截成一半的现象。
4. 连续左右滑动 20 次，观察回弹是否自然，动画结束后卡片是否回到中间。
5. 在 `MUSIC` 卡有封面时重复滑动，确认封面、曲名、按钮完整且按钮可点击。
6. 滑动中等待天气或音乐数据更新，确认界面不黑屏、不重启。
7. 进入诊断页再返回主页，再做 5 次滑动。

若仍看见固定在屏幕某一高度的水平断层，请记录它是在卡片移动中持续出现，
还是滑动结束后仍存在；两者分别指向显示刷新同步和卡片绘制问题。

# P1 音乐卡中文信息与封面实机验证

## 本轮目标

本轮在已经稳定的上一首、播放/暂停、下一首控制链路上增加：

- 显示网易云音乐当前歌曲的原始中文曲名和歌手；
- 从 Windows GSMTC 媒体会话读取 JPEG 专辑封面；
- 仅在歌曲封面变化时下载图片，日常状态轮询不重复传图；
- 没有媒体会话或没有封面时恢复 `NO COVER` 占位图；
- 超长 UTF-8 文本按完整字符边界截断，避免尾部乱码；
- 切歌时释放旧封面内存，并将大图等比例缩小到 220×220 居中区域内。

Codex 额度、联网天气和语音唤醒不在本轮验证范围内。

## 第一步：重启 Windows 助手

必须先停止旧版助手，否则面板无法取得新增的封面接口。打开原助手所在的
PowerShell 窗口，按 `Ctrl+C` 停止，然后在项目根目录重新执行：

```powershell
cd D:\Documents\ChatGPT\ESP32-P4-4B-Luna
.\pc-agent\start-agent.ps1
```

看到以下两行说明助手已启动并启用 Windows 媒体会话：

```text
Luna agent listening on http://0.0.0.0:8765
Windows media session synchronization is active.
```

## 第二步：烧录最新完整镜像

连接开发板的 USB TO UART 接口后，在另一个 PowerShell 窗口执行：

```powershell
cd D:\Documents\ChatGPT\ESP32-P4-4B-Luna
.\scripts\build-firmware.ps1 -Action flash-full -Port COM27
```

必须使用 `flash-full`，完整镜像从 `0x0` 写入，避免再次出现
`invalid header`。当前镜像的文件大小和 SHA-256 记录在本文档末尾。

## 第三步：验证静态显示

1. 打开网易云音乐 3.1.34，播放一首带中文歌名和封面的歌曲；
2. 等待面板 PC 状态变为就绪；
3. 音乐卡上方中央应显示当前专辑封面；
4. 封面下方应居中显示中文曲名和歌手，文字超出区域时以省略形式显示；
5. 上一首、播放/暂停、下一首按钮应分别位于底部左、中、右；
6. Windows 助手窗口应先出现 `GET /api/v1/state`，封面变化后出现一次
   `GET /api/v1/music/cover`；
7. 后续状态轮询不应每次都请求封面。

如果当前歌曲没有封面，显示 `NO COVER` 属于正常回退行为。

## 第四步：验证切歌和按钮状态

依次执行以下操作，每一步都等待界面状态更新：

1. 点击下一首，确认歌曲、歌手和封面一起更新；
2. 点击上一首，确认三项信息再次同步；
3. 点击播放/暂停，确认按钮文字最终与网易云真实状态一致；
4. 较快地连续点击播放/暂停三次，确认面板不重启，按钮不会永久停在错误状态；
5. 连续切换十首歌曲，确认封面持续更新且面板没有明显变慢或复位。

播放控制仍以 Windows GSMTC 的真实状态为准。点击后按钮会短暂禁用，命令
完成后重新读取实际状态，不依赖本地点击次数猜测播放状态。

## 第五步：验证无媒体回退

1. 完全退出网易云音乐；
2. 等待数秒；
3. 音乐卡应恢复无活动媒体提示；
4. 旧专辑封面应消失并显示 `NO COVER`；
5. 重新打开网易云并播放歌曲后，中文信息和封面应自动恢复。

## 故障排查

### 中文仍然显示方框或乱码

- 确认烧录的是本轮完整镜像；
- 确认旧版 Windows 助手已经停止并重新启动；
- 观察助手的 `/api/v1/state` 返回是否包含原始中文曲名；
- 提供歌曲名称和从复位开始的串口日志，便于判断是否是字库缺字。

### 封面一直显示 `NO COVER`

- 确认助手日志是否出现 `GET /api/v1/music/cover`；
- 确认网易云当前歌曲本身存在专辑封面；
- 确认面板与电脑仍在同一局域网；
- 若状态正常但封面接口返回 404，切换到另一首歌曲再试。

### 切歌或点击按钮后重启

本轮封面最大限制为 256 KiB，图片缓冲区在堆上分配；旧封面会在 LVGL 缓存
失效后释放。出现复位时，请保留从点击前开始的完整串口日志，以及同一时段的
Windows 助手 HTTP 日志。

如果在滑到音乐卡时出现 `Stack protection fault`，并且调用点是
`lv_tjpgd.c:decoder_info`，这是旧版 8 KB LVGL 任务栈在绑定 JPEG 封面时溢出。
当前版本已使用 16 KB LVGL 任务栈，并保留未变化封面的解码缓存。

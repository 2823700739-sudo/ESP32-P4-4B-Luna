# 590×450 音乐控制卡实机验证

## 本轮改动

- 所有主页卡牌改为 590×450 像素；位置保持垂直居中，左右邻卡各露出约 40 像素。
- 音乐卡播放键点击后立即显示目标图标；Windows 助手返回网易云实际状态后校正。若命令失败或长时间未确认，图标恢复为最近一次实际状态。
- 上一首、下一首点击后短暂高亮，表示触摸已经被接收。
- 右下角音量图标展开竖向滑条，拖动时滑块立即跟手，松手时把 0–100 的数值发给 Windows。弹层顶部仅保留静音键；Windows 返回静音状态后，图标在扬声器与静音形状之间切换。
- 音量控制的是 Windows 当前默认输出设备的系统主音量，即目前使用的电脑音箱。网易云关闭时也可使用。

## 更新步骤

本轮 Windows 助手和面板固件都改了。先在原助手窗口按 `Ctrl+C` 停止，再从项目根目录启动新版助手：

```powershell
.\pc-agent\start-agent.ps1
```

另开 PowerShell，连接开发板 USB TO UART，烧录本轮完整镜像：

```powershell
.\scripts\build-firmware.ps1 -Action flash-full -Port COM27
```

如需查看串口日志，执行 `-Action monitor -Port COM27`；监视器使用 `Ctrl+]` 退出。烧录前若 COM27 被其他程序占用，先关闭占用程序。

## 实机检查

1. 在网易云音乐播放带封面的歌曲，滑到音乐卡。确认卡牌为 590×450，唱片、曲名、歌手、底部控制按钮都完整显示，没有裁切或黑边。
2. 点击播放／暂停：中心图标应立即切换，随后与网易云的实际播放状态一致。连续测试几次，并在网易云手动暂停／播放后确认面板能同步。
3. 点击上一首和下一首：对应图标应短暂高亮，随后歌曲和封面更新；不应出现卡死或复位。
4. 点击右下角音量图标，打开弹层。拖动滑条到约 30%，松手后核对 Windows 音量界面和电脑音箱；再拖到约 70% 重测。拖动过程中滑块应跟手，不应被后台状态轮询拉回旧位置。
5. 点击弹层顶部静音图标：Windows 应静音，图标变成静音形状；再次点击，应取消静音并恢复扬声器形状。静音时滑条仍显示原有音量值。
6. 退出网易云后重测滑条和静音键；再连续左右滑动 30 次，检查邻卡露出宽度、弹层、触控、滑动流畅度及是否复位。

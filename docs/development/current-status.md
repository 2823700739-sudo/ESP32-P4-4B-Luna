## 当前产品

720×720 五张横滑卡片：数字时钟、固定音乐播放器、Wi-Fi 天气、Codex 双额度/VS Code 项目、电脑 CPU/GPU/RAM/VRAM。整屏繁星、可互动像素小猫、三针待机表盘。开机显示数字时钟。

Windows 配套 Agent 通过已配对、加密认证的 BLE 与设备通信。天气独立由设备 HTTPS 获取；校时 BLE 优先、Wi-Fi NTP 备用。UART COM27 只用于开发，Agent 不打开串口、不提供 HTTP，不传封面。温度没有可靠提供者时明确不可用，不安装额外驱动。

顶部空白点击或 180 秒无输入进入待机；首次触摸仅唤醒回原卡，不穿透执行操作。屏幕亮度不变、CPU 固定 360 MHz；待机减少界面工作，不进行整机休眠。详见[待机策略](standby-power-20261002.md)。

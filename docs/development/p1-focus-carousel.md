# 卡牌聚焦效果实机验证

## 本轮改动

- 中央卡牌为 `580×460` 像素；本次将高度从 `450` 增至 `460`，并上移
  `5` 像素以保持垂直中心不变。卡牌间距为 `30` 像素，两侧仍各露出约
  `40` 像素。音乐按钮按卡宽均匀分布。
- 当前卡保持清晰；左右邻卡叠加半透明柔焦雾层，边框变淡并稍微下沉。
- 滑动时根据卡牌与屏幕中心的距离连续调整雾层、边框和位置；新卡到中心时
  恢复清晰，旧卡退到侧边时变淡。
- 左右邻卡各露出约 40 像素，柔焦雾层比上一版更浓。没有使用实时高斯模糊或整卡缩放，避免额外
  图层占用内存和加重刷新负担。此处的“模糊感”是柔焦雾化效果。
- 聚焦强度按 12 级更新，减少动画期间反复修改样式；已完全滑出屏幕的卡牌
  停在屏外，不再随每帧移动。
- 滑动期间暂缓音乐封面应用；主页不再刷新只供诊断页使用的麦克风电平条。
- 仍只保留当前卡与两侧卡牌对象，语音控制保持关闭。

## 烧录

在项目根目录运行：

```powershell
.\scripts\build-firmware.ps1 -Action build
.\scripts\build-firmware.ps1 -Action flash -Port COM27
.\scripts\build-firmware.ps1 -Action monitor -Port COM27
```

串口监视器使用 `Ctrl+]` 退出。本轮没有修改 Wi-Fi、Windows 助手或 C6 固件。

## 实机检查

1. 开机停在 `CODEX`：中间卡应比上一版更宽、更高，两侧 `CLOCK`、`MUSIC`
   各露出约 40 像素，卡牌之间仅留约 30 像素背景；不应出现黑块或底部裁切。
2. 向左慢滑到 `MUSIC`：新卡进入中心时逐步变清晰，旧卡退到侧边时逐步变淡。
   停稳后 `MUSIC` 的封面、歌名与三个按钮应清楚可见；按钮应在卡牌底部
   左、中、右均匀分布，并且都可以点击。
3. 继续经过 `WEATHER`、`CLOCK` 并回到 `CODEX`；反方向再走一轮。每张卡
   到中间时都应完全清晰，不应残留雾层。
4. 快速左右滑动 30 次，观察有无半屏黑边、撕裂、明显掉帧、卡死或复位。
5. 在音乐播放、有专辑封面和天气数据更新时重复滑动，检查封面、文本、
   播放按钮及天气内容是否正常。
6. 进入诊断页确认麦克风电平条仍能变化，再回主页快速滑动；观察是否比上一版
   更平顺。没有实机测速前，不把编译通过当作帧率提升的证明。

如视觉太浅或太浓，可记录具体卡牌与照片；后续可调整雾层透明度与两侧
露出宽度。本轮未实测设备帧率。
